# VS Code vs терминал для работы с Git

## Что удобно в VS Code (Source Control)

1. Наглядный diff прямо в редакторе — открывается сразу с подсветкой добавленных/удалённых строк, не нужно читать unified diff в консоли.
2. Коммит через UI в два клика: ввёл сообщение в поле вверху панели, нажал ✓ — не нужно вспоминать флаги `git commit -m`.
3. GitLens показывает, кто и когда изменил каждую строку файла, прямо во время чтения кода (визуальный `git blame`), без отдельной команды.

## Что удобнее делать в терминале

Сложные операции вроде интерактивного rebase, cherry-pick или разрешения нетривиальных конфликтов — быстрее и прозрачнее выполнять командами напрямую: видно каждый шаг, легче понять, что произошло, и это единственный вариант, который точно будет работать на сервере без графического интерфейса.
